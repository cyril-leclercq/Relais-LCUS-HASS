# Volet Roulant Relais USB - Intégration HACS

Intégration Home Assistant pour contrôler un volet roulant via un module relais USB 2 canaux.

## Fonctionnalités

✅ **Configuration via l'UI** - Aucun YAML requis  
✅ **Compatible HACS** - Installation en un clic  
✅ **Support Docker** - Fonctionne dans les conteneurs  
✅ **Multilingue** - Français et anglais  
✅ **Automatisations** - Intégration native avec Home Assistant  

## Installation rapide

1. Installez via **HACS**
2. Ajoutez l'intégration dans **Paramètres → Intégrations**
3. Configurez votre port USB
4. C'est prêt !

## Matériel requis

- Module relais USB 2 canaux (9600 bauds)
- Câble USB
- Volet roulant motorisé
